1 引言

1.1 什么是 R？

R 是面向对象数学编程语言 S 的一种实现。它由世界各地的统计学家开发，是依据 GNU 通用公共许可证发布的自由软件。在语法与功能上，它与流行的统计软件包 S+ 非常相似（即便不完全相同）。

1.2 R 比其他软件包好在哪里？

对计量经济学家常用的多数软件而言，R 要灵活得多，因为它是一门现代数学编程语言，而不仅仅是“做回归和检验”的程序。这意味着我们的分析不必局限于默认安装所提供的函数。网上有大量且不断扩展的程序库，覆盖许多学科。研究者开发出新算法与流程后，相应的程序库会发布到 R 网站上。从这个意义上说，R 始终站在统计知识的前沿。又因 R 编程简便灵活，扩展起来也很容易。

S 语言事实上是统计科学的标准。阅读统计文献时，我们会发现例子甚至伪代码都用与 R 兼容的语法书写。由于多数用户有统计学背景，R 专家使用的术语有时与计量经济学家（尤其是初学者）的期望不同。本文的一个主要目的，就是消除这种语言隔阂，让计量经济学家能够利用这些富有创新精神的统计学家的工作成果。

为 R 编写的代码可在多种计算平台上运行，无论有无图形用户界面；并且 R 自带一些目前最灵活、最强大的图形例程。

当然，R 对任何用途都完全免费。

1.3 获取 R

可从 http://www.r-project.org 免费下载 R 安装程序。因为 R 是编程语言而不只是计量经济学程序，我们关心的多数函数要通过从 R 网站获取的程序库（有时也称包）来使用。要获得标准安装未附带的库，请在上述网站点击 CRAN 链接。在 contrib 下可找到已压缩、可供下载的程序库列表。点击所需项目，保存到稍后能找到的位置。若使用图形界面，启动 R，在 Package 菜单下选择“从本地目录安装包”，再选择下载的文件。之后该包即可长期使用。若在 Linux 下使用 R，可在命令提示符执行：

R CMD INSTALL packagename

也可以在 R 内部一次完成下载与安装，例如：

> install.packages(c("car","systemfit"),repo="http://cran.stat.ucla.edu",dep=TRUE)

这会安装 car 与 systemfit 库。repo 参数通常会自动配置，一般不必指定。dependencies（或 dep）表示 R 也应下载它们所依赖的包，建议开启。注意：必须拥有计算机的管理员（或 root）权限才能安装程序与包。

1.4 交互式使用 R 与编写脚本

我们可通过命令提示符直接与 R 交互。在 Windows 下，提示符与我们输入的内容一般为红色，返回的输出为蓝色——也可通过 Edit 菜单中的 “GUI preferences” 控制字体颜色。按向上箭头通常可循环浏览历史命令。注意：R 区分大小写，并且每个函数调用末尾都有括号。除直接输入命令外，也可加载事先写好的脚本文件，其中可包含新的函数定义。

脚本文件一般扩展名为 “.R”。这些文件包含与在提示符下输入相同的命令；凡超过几行的项目，都建议使用脚本。要加载名为 mcmc.R 的脚本，可使用：

> source("mcmc.R")

一种用法是：在外部文本编辑器中打开脚本，再定期从 R 窗口运行。从脚本执行的命令打印到屏幕的输出，可能不如交互式运行时多。若希望达到交互级的详细程度，可使用 echo 参数：

第 7 页
> source("mcmc.R",echo=TRUE)

若未指定脚本路径，R 假定文件位于当前工作目录。可用 R 命令查看或更改工作目录：

> getwd()
[1] "/home/gvfarns/r"
> setwd("/home/gvfarns")
> getwd()
[1] "/home/gvfarns"

在 Windows 下也可通过菜单项 “change working directory”。另请注意：在较旧的 Windows 版 R 中，斜杠须换成双反斜杠。

> getwd()
[1] "C:\\Program Files\\R\\rw1051\\bin"
> setwd("C:\\Program Files\\R\\scripts")
> getwd()
[1] "C:\\Program Files\\R\\scripts"

在 Linux 下也可用批处理（非交互）模式运行 R，命令为：R CMD BATCH scriptname.R。输出将保存到名为 scriptname.Rout 的文件。Windows 下同样有批处理模式，使用 Rcmd.exe 而非 Rgui.exe。

由于我们将使用的每个命令都是某个库中存储的函数，开始工作前往往需要先加载库。许多常用函数在默认加载的 base 库中。要使用其他任何函数，则须加载相应的库：

> library(foreign)

这将加载包含读写其他程序（如 SAS、Stata）格式数据之函数的库。在 Windows 下，也可下拉 Package 菜单并选择 library。

1.5 获取帮助

在 R 中有多种获取帮助的方法：

> ?qt
> help(qt)
> help.start()
> help.search("covariance")

在命令前加问号，或把它作为 help() 的参数，可得到用法与功能说明。help.start() 会打开帮助选项菜单；help.search() 则在帮助文件中搜索作为参数给出的词或短语。不过很多时候，最好的帮助来自网上搜索。搜索时请记住：R 的语法与功能与商业统计软件包 S+ 几乎相同。

上述帮助工具只搜索你计算机上已安装包中的 R 函数。我听到的大量 R 问题都形如：“R 有没有函数可以做……？”用户不知道功能是否存在，往往是因为相应包尚未安装。要在 R 网站上搜索函数与文献，可使用：

> RSiteSearch("Kalman Filter")

搜索结果应会显示在你的网页浏览器中。

2 处理数据

2.1 基本数据操作

R 允许创建多种数据存储对象，如数值、向量、矩阵、字符串与数据框。ls() 列出当前所有可用数据对象；rm() 删除作为参数给出的数据对象。可用 typeof() 判断对象类型，或用通常更有信息量的 class() 查看其类。

输入对象名通常会把它的数据回显到屏幕。事实上，在 R 中函数也只是另一种数据成员。输入不带括号的函数名，即可看到其代码。

创建和/或给数据对象赋值的命令是小于号后接减号：

> g <- 7.5

这创建名为 g、值为 7.5 的数值对象。在需要区分时，R 中真正的向量（相对于一维矩阵）被当作列向量。

> f <- c(7.5,6,5)
> F <- t(f)

用 c()（concatenate，连接）创建值为 7.5、6、5 的向量。c() 是可用于多种数据类型的泛型函数。t() 对 f 转置，得到 1×2 矩阵——因为“向量”总是列向量。由于 R 区分大小写，f 与 F 是不同对象。cbind() 把给定对象左右拼接：若是向量则成数组，若是带名称数据的列则成单个数据框。

> dat <- cbind(c(7.5,6,5),c(1,2,3))

类似地，rbind() 按行拼接——一个在另一个之上——并假定给定的向量是行向量（见 2.3.1）。

注意：若连接的是字符串而非数值，须给字符串加引号。也可使用 Hmisc 库中的 Cs()，它无需引号：

> Cs(Hey,you,guys)
[1] "Hey" "you" "guys"

向量及类似数据类型用方括号索引。R 使用从 1 开始的索引。

> f
[1] 7.5 6.0 5.0
> f[2]
[1] 6

对多维类型（如矩阵与数据框），某一维索引留空表示该维整列或整行。因此若 foo 是 4×5 数值数组：

> foo

会打印整个数组；

> foo[1,]

打印第一行；

> foo[,3]

打印第三列，等等。可用 summary() 得到数据摘要统计，用 NROW()、NCOL() 了解维数。更一般地，对许多 R 对象可用 dim() 获取维度。

若只想提取或打印某些行或列，可用连接运算符。

第 9 页
> oddfoo <- foo[,c(1,3,5)]

从 foo 的第 1、3、5 列得到 4×3 数组并存入 oddfoo。在索引前加负号可去掉某些列：

> nooddfoo <- foo[,-c(1,3,5)]

从第 2、4 列得到 4×2 数组（即去掉第 1、3、5 列）。也可用比较运算符提取某些列或行：

> smallfoo <- foo[foo[,1]<1,]

把 foo 第一列每个元素与 1 比较，把匹配的行放入 smallfoo。还可重排数据。若 wealth 是含 year、gdp、gnp 列的数据框，可用 order() 按年份排序，或用冒号运算符提取某段年份：

> wealth <- wealth[order(wealth$year),]
> firstten <- wealth[1:10,]
> eighty <- wealth[wealth$year==1980,]

这按年份排序，并把前十年放入 firstten。1980 年的所有行存入 eighty（注意双等号）。

索引用双方括号而非单方括号时行为略有不同。基本上，它不允许像单括号那样用索引向量引用多个对象。例如：

> w[[1:10]]

不会像单括号那样返回 w 的前十个元素组成的向量。此外，它会剥去属性与类型。若变量是列表，单括号索引得到含数据的列表，双括号返回数据本身（向量）。从列表取值时多数情况要用双括号，否则单括号更常见。

偶尔数据形式不对（例如是数据框但我们更想要矩阵）。此时可用 as. 系列功能。若 goo 中全部为数值，可用下式放入名为 mgoo 的矩阵：

> mgoo <- as.matrix(goo)

其他数据操作见标准 R 手册与网上资料，数量很多。

2.2 注意：数学运算与循环使用规则

加、乘等数学运算默认按元素进行。矩阵代数运算一般用 % 包围（见第 8 节）。危险在于：对不同大小的某些对象做运算时，R 不会像人们预期的那样中止并报错，而是用循环使用规则（recycling rule）决定如何计算——即重复较小对象中的值。例如：

> a<-c(1,3,5,7)
> b<-c(2,8)
> a+b
[1] 3 11 7 15

仅当维数不是彼此的倍数时，R 才给出警告（但仍会计算）：

> a<-c(2,4,16,7)
> b<-c(2,8,9)
> a+b
第 10 页
[1] 4 12 25 9
Warning message:
longer object length
is not a multiple of shorter object length in: a + b

乍看循环使用规则像是笨主意（程序员不小心时确实会出错），但正是它使标量加、标量乘向量/矩阵（以及向量与矩阵相加）成为可能。在 R 中做按元素运算时，只需对维数格外小心。

注意：虽然向量与其他向量或数据类型相加时会循环使用，但两个矩阵相加时不会。不同维数的矩阵或数组相加会产生错误。

2.3 重要的数据类型

2.3.1 向量

R 中最基本的数值数据类型是未命名向量。标量实际上是长度为 1 的向量。向量比一维矩阵更抽象，因为它们不含“行向量还是列向量”的信息——尽管必须区分时，R 通常假定向量是列。

这种脱离行/列的抽象，常使熟悉 Matlab 等面向矩阵语言的人感到困惑。可用一例说明：

a<-c(1,2,3)
b<-c(4,6,8)

现在可竖直或水平堆叠成矩阵；R 分别假定这些向量是列或行：

> cbind(a,b)
  a b
[1,] 1 4
[2,] 2 6
[3,] 3 8
> rbind(a,b)
  [,1] [,2] [,3]
a    1    2    3
b    4    6    8

一个函数把它们当作列向量，另一个当作行向量。要点是：向量不是一维矩阵，不要指望它们在线性代数世界中那样工作。要把向量转为用于线性代数运算的 1×N 矩阵（列向量），请用 as.matrix()。

注意 t() 返回矩阵，因此 t(t(a)) 与 a 并不相同。

2.3.2 数组、矩阵

在 R 中，同质（所有元素类型相同）的多元数据可存为数组或矩阵。矩阵是二维对象，而数组可以有很多维。这些类型可有（也可没有）给列或行命名的特殊属性（但不能像数据框那样用 $ 引用列），且只能保存数值数据。注意：不能把数值与字符等两种不同类型放进同一个矩阵、数组或向量。要么会被强制为同一类型，要么会报错。

2.3.3 数据框

大多数计量数据会以数据框（dataframe）的形式存在。数据框是一组向量的集合（可把它们想成列），各列数据类型不必相同，但每一列的元素个数必须相同。每列都有一个标题，可用标题引用整列向量。若 goo 是一个 3×4 的数据框，列名为 age、gender、education 和 salary，则可用下列命令打印 salary 列：

> goo$salary

或查看 goo 的列名：

> salarysq <- (goo$salary)^2

2.3.4 列表

列表（list）比数据框更一般。它本质上是把一堆数据对象绑在一起，并可选择性地给每个对象命名。这些对象可以是标量、字符串、数据框或任何其他类型。返回多种数据的函数（如 summary()）通常把返回值绑成列表，因为函数只能返回一个数据对象。与数据框类似，可用 names() 查看列表中有哪些对象（若有名称），并可用 $ 按名称引用，或用方括号按编号引用。请记住：引用列表成员一般用双括号而非单括号（见 2.1 节）。有时我们希望把列表简化成向量。例如，strsplit() 返回包含参数子串的列表；要得到字符串向量，须用 unlist() 把列表转成向量。列表有时很烦人，因而 unlist() 是出人意料地有用的函数。

2.7 处理超大数据文件

R 对象可以大到物理内存（以及操作系统）允许的程度，但它并非为超大数据集设计。这意味着极大对象会严重拖慢一切，并贪婪地吞噬 RAM。read.table() 系列例程假定我们不处理超大数据集，因而并不特别节省内存1。它们一次载入全部数据，并很可能至少再复制一份。处理巨大数据集的更好方式是一次读入一行（或一组行）。我们通过连接（connection）来做这件事。连接是指向文件或其他输入/输出流的 R 对象。每次从连接读取时，文件中的读取位置会向前移动。

使用连接前，若数据源是文件须用 file() 创建，若是在线源则用 url()（还有其他类型的连接）。然后用 open() 打开。现在可用 readLines() 读取一行或多行文本，用 scan() 读取数据字段，或用 cat() 或 write.table() 系列例程写出数据。完成后用 close() 关闭。

2.7.1 用 scan() 读取数据字段

从巨大文件中读取数据字段是很常见的任务，因此特别说明。scan() 最重要的参数是 what，它指定要读入的数据类型。若文件含多列数据，what 应为列表，列表的每个成员代表一列。例如，若文件中是姓名后跟逗号分隔符再跟年龄，可用

> a <- scan(f,what=list(name="",age=0),sep=",",nlines=1)

读取单行，其中 f 是已打开的连接。此时 a 是带有字段 name 与 age 的列表。例 13.4 展示了如何从大文件读取。

若连接已到达文件末尾仍尝试 scan，则 scan() 返回空列表。可用 length() 检查以终止循环。

我们常常知道每行有多少字段，并希望确保 scan() 读到全部字段，缺失的用 NA 填充。为此指定 fill=T。注意在许多情况下 scan() 本来也会用 NA 填充空字段。

不幸的是，若 scan 读到的数据与期望不符，会返回错误。例如，若上例年龄列出现字符串 "UNK"，就会出错。若只有少数几种例外，可把它们作为 na.strings 传给 scan()。否则需要先把数据读成字符串，再用 as.numeric() 或其他工具转换成数值等类型。

注意：一次读一行并非最快方式。R 可轻松一次读 100、1000 或更多行。增加每次迭代读取的行数可显著加快大文件读取。对大文件，可每次读 1000 行、变换后再向另一个打开的连接写出 1000 行，从而保持系统内存空闲。

若全部数据类型相同且属于同一对象（例如 2000×2000 数值矩阵），可不用 nlines 参数调用 scan()，从而获得快得多的读取。所得向量只需再转换成矩阵类型。

若在 linux/unix 机器上使用 R2，可用各种 unix 工具（如 grep 与 awk）只读取文件中你想要的列与行。grep 工具可筛出包含或不包含指定模式的行。编程语言 awk 是面向记录的工具，可按多种准则抽出并操作列与行。

2.7.3 用磁盘代替内存

不幸的是，R 默认只使用系统 RAM。因此若加载的数据集非常大，操作系统很可能无法为其分配足够大的一块系统 RAM，导致程序终止并提示 R 无法分配该大小的向量。虽然 R 没有内置磁盘缓存系统，但有一个名为 filehash 的包，允许把变量存在磁盘上而非系统 RAM 中。这显然会更慢，但至少只要有足够磁盘空间且文件大小未超出操作系统限制，程序就能运行。有时这至关重要。

> LL <- logLik(result)
> DegreesOfFreedom <- result$df

AIC = −2 log L(p) + 2p

这意味着

SBC = −2 log L(p) + p log(N)

4 特殊回归

4.1 固定/随机效应模型

警告：固定效应与随机效应模型的定义在各学科间并不统一。这里描述的是计量经济学家通常使用的固定效应与随机效应估计。“固定”与“随机”这些术语有历史根源，从计量角度看容易误导。

在经济学语境中，固定效应与随机效应估计量是处理截距截面变异的面板数据模型。令 i 表示截面指标（或数据分组所依据的指标），t 表示时间指标（或组内变化的指标），标准固定效应模型可写为

yit = α + ui + βXit + εit.　　(2)

本质上，每个个体有不同的时不变截距（α + ui）。我们通常关心 β 而不关心各个 ui。随机效应模型有相同的均值方程，但额外施加个体特定效应与解释变量 Xit 不相关的限制。即 E[ui Xit] = 0。从计量上看，这是固定效应估计量的更受限版本（固定效应允许“效应”与外生变量任意相关）。不要让不幸的命名混淆这些模型之间的关系。

4.1.1 固定效应

做固定效应估计的一种简单方式——尤其在截面维不太大时——是为每个个体加入虚拟变量，也就是把截面指标做成因子。若 index 标识样本中的个体，则

> lm(y~factor(index)+x)

会做固定效应估计，并报告 β 的正确标准误。不幸的是，当样本中个体很多且我们对他们的固定效应取值不感兴趣时，lm() 结果难以处理，估计大量 ui 系数也可能使问题在数值上难以处理。

估计固定效应模型更常见的方式是通过对每个变量做时间去均值（所谓组内估计量）来去掉固定效应。于是方程 (2) 变为

(yit − ȳi) = α + β(Xit − X̄i) + ζit.　　(3)

大多数计量软件包（例如 Stata 的 xtreg）做固定效应估计时使用该方法。在 R 中，可手动对自变量与因变量做时间去均值。若 d 是含 year、firm、profit 与 predictor 的数据框，我们想对每个公司的利润与预测变量做时间去均值，可运行类似：

> g<-d
> for (i in unique(d$firm)){
+   timemean<-mean(d[d$firm==i,])
+   g$profit[d$firm==i]<-d$profit[d$firm==i]-timemean["profit"]
+   g$predictor[d$firm==i]<-d$predictor[d$firm==i]-timemean["predictor"]
+ }
> output<-lm(profit~predictor,data=g)

注意：该回归报告的标准误会向下偏误。lm() 报告的 σ̂2 用

σ̂2 = SSR / (NT − K)

计算。

第 21 页

而该固定效应回归中真正的标准误为

σ̂2 = SSR / [N(T − 1) − K]

对于小的 T，这可能是重要的校正。

另一种通常较不受欢迎的固定效应估计方式是使用一阶差分估计量

(yit − yi(t−1)) = α + β(Xit − Xi(t−1)) + ζit.

可用与组内估计量类似的方式手工计算。

4.1.2 随机效应

nlme 包包含做随机效应回归的函数（但不含固定效应——文档采用统计学对“固定效应”一词的解释），框架可为线性或非线性。假设我们有对 sic3 代码带随机效应的线性模型：

ldsal = (α + αi) + β lempit + γ ldnptit + εit

可用下式拟合该模型：

> lme(ldsal~lemp+ldnpt,random=~1|sic3)

一般地，随机效应写在模型 random 参数中竖线之后。在波浪号与竖线之间放 1 表示随机效应是截距项。若还想对外生变量之一以及截距都有随机效应，可把该变量放在与 1 相同的位置。例如

> lme(ldsal~lemp+ldnpt,random=~1+lemp|sic3)

对应于

ldsal = (α + αi) + (β + βi) lempit + γ ldnptit + εit

对于非线性随机效应模型，用 nlme() 代替 lme()。

4.3 Tobit 与删失回归

4.4 分位数回归

普通最小二乘回归方法给出因变量在自变量条件下的期望的估计。因此拟合值是条件均值的估计。若我们想要的不是条件均值，而是条件中位数或其他分位数的期望估计，则使用 quantreg 包中的 rq() 命令。语法本质上与 lm() 相同，只是可指定参数 tau，即我们想要的分位数（介于 0 与 1 之间）。默认 tau=.5，对应于中位数回归——也就是最小绝对偏差回归的另一名称。

4.5 稳健回归——M 估计量

对某些数据集，异常值对最小二乘回归线的影响超过我们希望的程度。一种解决办法是用残差平方和（对应最小化 L2 范数）以外的目标函数做最小化。常见选择是绝对偏差之和（L1）以及 Huber 方法——它在某种程度上是 L1 与 L2 方法的混合。R 通过 MASS 库中的 rlm() 命令实现该稳健回归功能。语法与 lm() 命令相同，只是允许选择要最小化的目标函数。该选择由 psi 参数指定。可能已实现的选择有 psi.huber、psi.hampel 与 psi.bisquare。

要指定自定义 psi 函数，我们写一个函数：当 deriv=0 时返回 ψ(x)/x，当 deriv=1 时返回 ψ′(x)。然后可用 psi 参数把该函数传给 rlm()。

5 时间序列回归

R 有特殊数据类型 ts，用于时间序列回归。向量、数组与数据框可用 ts() 命令强制转换为此类型，以便用于时间序列函数。

> datats <- ts(data)

大多数与时间序列相关的函数会自动把数据强制为 ts 格式，因此该命令常常不必要。

5.1 差分与滞后

可用 diff() 运算符计算时间序列对象的差分；它接受可选参数，指定用几阶差分以及计算该差分时用多大滞后。例如，要取滞后为二的一阶差分，使得 wt = vt − vt−3，我们用

> w <- diff(v,lag=2,difference=1)

默认情况下，diff() 返回其参数的简单一阶差分。

生成滞后数据有两种一般方式。若想直接滞后数据（不必先转成时间序列对象），一种方式是用索引的减号运算符省略前几个观测。然后可去掉未滞后数据的最后几行以达到一致。命令

> lagy <- y[-NROW(y)]
> ysmall <- y[-1]

产生相对 ysmall 一次滞后的 y。若在回归中尝试滞后的各种组合，这种方式可能很别扭，因为对每个滞后版变量，一致性要求我们有去掉前几个观测的对应版原始数据。

另一种滞后数据的方式是转换成时间序列对象并使用 lag() 函数。非常重要的是要记住：该函数并不真正改变数据，它改变的是时间序列对象中指示序列起点的属性。这给时间序列函数带来更大灵活性，但对 lm() 等不理解时间序列属性的一般函数可能造成混淆。注意 lag() 仅对时间序列对象有用地工作。例如，代码片段

> d <- a - lag(a,-1)

若 a 是普通向量，会创建名为 d 的零向量；但若 a 是 ts 对象，则返回该序列一阶差分的 ts 对象。对常规数据使用 lag() 不会发出警告，因此应小心。

为在回归中使用滞后数据，可用时间序列函数生成数据框，其中含数据的各种滞后，并在所需的前导与尾随位置放入 NA。为此使用 ts.union() 函数。假设 X 与 Y 是普通数据向量，我们想在回归中包含三次滞后的 X，则

> y <- ts(Y)
> x <- ts(X)
> x3 <- lag(x,-3)
> d <- ts.union(y,x,x3)

把向量转为 ts 数据，并形成多元时间序列对象，列分别为 yt、xt 与 xt−3。再次记住：数据必须先转成时间序列格式再滞后，或用 union 运算符绑在一起，才能得到期望的偏移。ts.union() 函数会像 data.frame() 命令一样自动决定每列标题。我们也可在 union 内部做滞后并自行指定标题：

> y <- ts(Y)
> x <- ts(X)
> d <- ts.union(y,x,x1=lag(xt,-1),x2=lag(xt,-2),x3=lag(xt,-3))

必须注意：滞后运算符的方向与人们可能预期的相反：正的滞后值导致超前（lead），负的滞后值导致滞后（lag）。

当所得多元时间序列对象转换成数据框时（例如被 ls() 读取时），偏移会被保留。于是

> lm(y~x3,data=d)

会把 yt 对 xt−3 回归。

还要注意：默认情况下，含缺失值（NA）的观测会被省略。这正是我们想要的。若默认设定不知何故被更改，应在 lm() 调用中包含参数 na.action=na.omit。为获得正确的省略行为，一般有必要把我们想用的全部数据（因变量与自变量）绑在同一个 union 中。

总结：要使用时间序列数据，把全部数据转成类型 ts，适当地滞后（采用正滞后为超前这一奇怪约定），并用 ts.union() 全部绑在一起。然后继续做回归及其他操作。

5.2 滤波器

5.2.1 现成的 AR 与 MA 滤波器

可用 filter() 命令让数据通过由滞后算子多项式构造的滤波器。它处理两类主要滤波器：移动平均或“卷积”滤波器，以及自回归或“递归”滤波器。卷积滤波器形如

y = (a0 + a1L + … + apLp) x

而递归滤波器求解

y = (a1L + a2L2 + … + apLp) y + x

在两种情形下，x 是滤波器输入，y 是输出。若 x 是新息向量，卷积滤波器生成移动平均序列，递归滤波器生成自回归序列。注意递归滤波器中没有 a0 项（理论上说不通）。递归滤波器等价地可看作求解

y = (1 − a1L − a2L2 − … − apLp)−1 x

使用 filter() 命令时，我们如下提供 {an} 向量：

> y <- filter(x,c(1,.2,-.35,.1),method="convolution",sides=1)

数据向量 x 可以是时间序列对象或普通数据向量，输出 y 将是 ts 对象。对卷积滤波器必须指定 sides=1，否则软件会尝试（在正负滞后上）居中滤波器，这通常不是计量经济学家想要的。递归滤波器忽略 sides 关键字。注意（除序列开头附近的数据损失外）我们可用递归滤波器从上面的 y 恢复数据：

> X<-filter(y,c(-.2,.35,-.1),method="recursive")

5.2.2 手动滤波

若 filter() 命令不适用于我们的应用——或者我们只是更喜欢自己动手——可手动生成滞后并计算结果。可用下列方式模仿上面的卷积滤波器：

> x <- ts(x)
> y <- x+.2*lag(x,-1)-.35*lag(x,-2)+.1*lag(x,-3)

自回归滤波器则需要 for 循环来复现。记住：滞后滤波方法仅在 x 是 ts 对象时才会工作。

5.2.3 Hodrick–Prescott 滤波

可用几种方式对数据做 Hodrick–Prescott 滤波，都不要求数据必须是时间序列向量。首先，可用下面定义的函数手动滤波（为便于复制粘贴到 R，此处不含提示符）：

hpfilter <- function(x,lambda=1600){
  eye <- diag(length(x))
  result <- solve(eye+lambda*crossprod(diff(eye,lag=1,d=2)),x)
  return(result)
}

其中 lambda 是标准调节参数，对宏观经济数据常取 1600。把序列传入该函数会返回平滑后的序列。

该滤波也是 smooth.spline() 在传入参数 all.knots=TRUE 时的一个特例。可惜 smooth.spline() 的调节参数 spar 与上面的 lambda 不同，我们尚未弄清如何在 spar 与 lambda 之间换算。若读者知道如何用 smooth.spline() 做 HP 滤波，请告知作者。

5.2.4 卡尔曼滤波

R 有多个函数可用卡尔曼滤波对状态空间模型做平滑、滤波并计算似然。最常被提到的是 KalmanLike 一族，但它们只适用于一元状态空间模型（即观测方程中只有一个变量）。因此，人们往往更偏爱 dse1 包中的方法（如 SS.l() 等）以及 sspir 包。因其更简单，这里介绍 sspir 包中的函数。

首先用函数生成状态空间模型对象，然后可对其做卡尔曼滤波，并可选择对滤波结果做平滑。生成状态空间对象的函数是 SS()。回顾状态空间模型可写成

yt = F′tθt + vt， θt = Gtθt−1 + wt

其中

vt ∼ N(0, Vt)， wt ∼ N(0, Wt)。

θt 是不可观测的状态向量，yt 是观测数据向量。做卡尔曼滤波时，θ 的初值从 N(m0, C0) 抽取。

由于该一般模型可能随时间变化，系数矩阵必须以函数形式给出。一个要注意的细节是：输入 Fmat 是 Ft 的转置。写好生成 Ft、Gt、Vt、Wt 的函数，并生成输入变量 φ（供这些函数使用的参数向量）、m0 与 C0 后，运行 SS() 创建状态空间模型。然后对该模型对象运行 kfilter() 以滤波并得到对数似然——它返回带有估计参数的模型副本。若要做卡尔曼平滑，则把 kfilter() 输出的模型再交给 smoother()。

dse1 包中的函数看起来更灵活，但初始化更复杂。

5.3 ARIMA/ARFIMA

ts 库中的 arima() 命令可用自回归积分滑动平均模型拟合时间序列数据。

Δdyt = μ + γ1Δdyt−1 + ⋯ + γpΔdyt−p + εt + θ1εt−1 + ⋯ + θqεt−q (7)

其中

Δyt = yt − yt−1 (8)

参数 p、d、q 指定 ARIMA 模型的阶数。这些值以向量 c(p,d,q) 传给 arima()。注意：R 所用模型对 θ 项的符号不做假定，因此对应系数的符号可能与其他软件包（如 S+）不同。

> ar1 <- arima(y,order=c(1,0,0))
> ma1 <- arima(y,order=c(0,0,1))

数据成员 ar1 与 ma1 分别包含用 AR(1) 与 MA(1) 拟合 y 得到的估计系数，以及对数似然统计量与估计标准误。

有时我们想估计高阶 ARIMA，但把前几个系数固定为 0（或其他值）。可用 fixed 参数做到这一点。它接受一个长度等于可估参数个数的向量。条目为 NA 表示希望估计对应参数。例如，要估计

yt = γ2yt−2 + θ1εt−1 + εt (9)

可用

> output <- arima(y,order=c(2,0,1),fixed=c(0,NA,NA))

有人报告：若使用 fixed 参数，还应传入 transform.pars=FALSE。

若只建简单自回归模型，也可用 ts 包中的 ar() 命令：它可接受模型阶数，或选择一个合理的默认阶数。

> ar3 <- ar(y,order.max=3)

例如拟合 AR(3) 模型。

fracdiff 库中的 fracdiff() 对我们的数据拟合指定的 ARMA(p,q)，并寻找 ARFIMA(p,d,q) 中最优的分数阶 d。其语法与 arima() 略有不同。

> library(fracdiff)
> fracdiff(y,nar=2,nma=1)

在 p=2、q=1 下寻找最优 d，然后估计所得 ARFIMA(p,d,q) 模型。

5.4 ARCH/GARCH

5.4.1 基本 GARCH——garch()

R 可用广义自回归条件异方差模型 GARCH(p,q) 数值拟合数据，写为

yt = C + εt (10)

σ2t = α0 + δ1σ2t−1 + ⋯ + δpσ2t−p + α1ε2t + ⋯ + αqε2t−q (11)

令 p = 0 即得 ARCH(q) 模型。R 命令 garch() 来自 tseries 库。其语法为

> archoutput <- garch(y,order=c(0,3))
> garchoutput <- garch(y,order=c(2,3))

从而 archoutput 是 ARCH(3) 的建模结果，garchoutput 是 GARCH(2,3) 的建模结果。注意：order 参数的第一个值是 p（delta 的个数），第二个值是 q（alpha 参数的个数）。所得系数估计会命名为 a0、a1、…（对应 alpha）以及 b1、b2、…（对应 delta）。条件标准差过程的估计值可通过

fitted(garchoutput)

获得。

5.4.2 高级 GARCH——garchFit()

当然，我们可能想在均值方程 (10) 中加入外生变量，而 garch() 不允许。为此可使用 fSeries 包中更灵活的函数 garchFit()。

> garchFitoutput <- garchFit(~arma(0,1)+garch(2,3),y)

拟合与上面相同的模型，但均值方程现为 MA(1)。

该函数返回 S4 类对象，意味着要用 @ 运算符访问内部数据：

> coef <- garchFitoutput@fit$coef
> fitted <- garchFitoutput@fit$series$h

这里 h 给出的是估计的 σ2 过程，而非 σ，因此它是上面 garch() 的“fitted”值的平方。撰写本文时，garchFit() 在估计参数时会打印大量输出。传入参数 trace=FALSE 可避免其中一部分。

> library(ts)

8.2 数值优化

8.2.1 无约束最小化

8.2.2 带线性约束的最小化

受线性不等式约束的函数最小化由 constrOptim() 提供。约束集必须能写成

U′iθ − Ci ≥ 0

θ̂ = arg maxθ : θ′mi ≤ 1 f(θ)

我们会使用

> thetahat<-constrOptim(c(0,0,0,0,0),-f,NULL,ui=-m,ci=-1)$par

第一个参数是起始值（θ 有五个参数）；函数乘以 −1 因为我们在最大化。下一个参数应是给出 f 梯度的函数。若没有这样的函数，必须插入 NULL，以便使用非梯度优化方法。

9 编程

9.1 编写函数

在 R 中，函数可像其他任何对象一样对待。用赋值运算符与 function() 创建；后者传入参数列表（用等号表示默认参数；其余参数在运行时必需）。作用于参数的代码跟在后面；若超过一行则用花括号包围。

若在函数内求值表达式或变量，它不会回显到屏幕。但若它是函数内的最后一次求值，它将充当返回值。这意味着下面两个函数等价：

> g <- function(x,Alpha=1,B=0) sin(x[1])-sin(x[2]-Alpha)+x[3]^2+B
> f <- function(x,Alpha=1,B=0){
+   out <- sin(x[1])-sin(x[2]-Alpha)+x[3]^2+B
+   return(out)
+ }

注意：R 把提示符改为 “+”，提醒我们仍在括号内。

因为 R 不区分参数列表中变量是何种数据对象，编写函数时应小心。若 x 是向量，上述函数会返回同维向量。另外，若参数名较长，只要缩写唯一即可缩写。因此下面两条语句等价：

> f(c(2,4,1),Al=3)
> f(c(2,4,1),Alpha=3)

函数参数按值传递，因此在函数内修改它们不会改变函数外的值。函数内定义的变量在函数外也不可用。若在函数内引用某变量，先检查函数作用域，再检查上一层作用域，等等。换言之，函数外的变量对函数内代码可读，但对函数外已定义变量所做的修改会在函数终止时丢失。例如，

> a<-c(1,2)
> k<-function(){
+   cat("Before: ",a,"\n")
+   a<-c(a,3)
+   cat("After: ",a,"\n")
+ }
> k()
Before:  1 2
After:  1 2 3
> a
[1] 1 2

若函数希望写入其上一层作用域中定义的变量，可使用“超级赋值”运算符 <<-。程序员在使用该运算符前应再三考虑程序结构。对它的需求很容易来自不良编程习惯。

9.3.1 对数组（或其截面）应用函数

为帮助程序员避免编写与执行循环带来的迟缓，R 有命令可对数组的每一行或每一列调用函数。我们指定数组的某一维，对该维的每个元素，把所得截面传给函数。

例如，若 X 是 50×10 数组，表示与 50 个个体相关的 10 个量，我们想求每行（或每列）的均值，可写

> apply(X,1,mean)  # for a 50-vector of individual (row) means
> apply(X,2,mean)  # for a 10-vector of observation (column) means

当然，数组可以超过二维，因此第二个参数（对其应用函数的维）可以大于 2。对本例更好的做法当然是使用 rowMeans() 或 colMeans()。

> apply(X,c(1,2),qnorm,mean=3,sd=4)

返回 50×10 的正态分位数矩阵。在必需的三个参数之后，任何额外参数都会传给内部函数（此处为 qnorm）。

要对列表、向量或其他 R 对象的每个成员执行函数，可用 lapply()。结果将是新列表，其每个元素是对输入每个元素执行所给函数的结果。语法与 apply() 相同，但不需要维属性。若要以向量而非列表得到这些函数求值结果，可用 sapply()。

9.9.1 如何编写 C 代码

将从 R 内调用的函数应为 void 类型（除通过参数外不应返回任何值）。值按引用在 R 与 C 之间传递，故所有参数都是指针。实数（或向量）以 double* 传递，整数与布尔以 int* 传递，字符串以 char** 传递。若函数输入为向量，应手动传入其长度。另请注意：矩阵与数组等对象只是带有维数属性的向量；传入 C 时只传向量本身，故应手动传入维数，必要时在 C 中重建矩阵。

下面是计算两向量点积的 C 文件示例：

void gdot(double *x,double *y,int *n,double *output){
  int i;
  *output=0;
  for (i=0;i<*n;i++){
    *output+=x[i]*y[i];
  }
}

除非需要更高级功能（例如传递复数——以特定 C 结构传递），否则无需包含头文件。需要时请包含 R.h。

在与 R 配合使用的 C 代码中，不要使用 malloc() 或 free()，而应使用 R 函数 Calloc() 与 Free()。R 有自己的内存管理，与默认 C 内存机制混用是坏主意。

9.9.2 如何使用已编译函数

要编译库，在命令行（而非 R 内部）使用：

R CMD SHLIB mycode.c

这将生成名为 mycode.so 的共享库。要从该库调用函数，先用 dyn.load() 加载，再用 .C() 命令调用。该命令复制各参数并全部按引用传给 C，然后以列表形式返回它们。例如，要调用上面的点积函数，可用：

> x<-c(1,4,6,2)
> y<-c(3,2.4,1,9)
> dyn.load("mycode.so")
> product<-.C("gdot",myx=as.double(x),myy=as.double(y),
+              myn=as.integer(NROW(x)),myoutput=numeric(1))
> product$myoutput
[1] 36.6

注意调用 .C() 时给参数起名只是为了方便（使结果列表也带有名称）；名称不会传给 C。好习惯（且常常必要）是对传给 .C() 的每个参数使用 as.double() 或 as.integer()。若编译代码不工作或不正确，应首先检查这一点。

重要的是：将传给 .C() 的任何向量都应先在 R 中创建。若传入数据很大、不希望为传递而复制，可通过 DUP=FALSE 指示 .C() 就地编辑数据。这样做时程序员应非常谨慎，因为 C 代码中改动的任何变量在 R 中也会改变，且有微妙陷阱。.C() 的帮助文件或在线文档有更多信息。

还有 .Fortran() 函数。注意 .C() 与 .Fortran() 是从这些语言调用函数的简单方式，它们不处理 NA 值或复杂 R 对象。更灵活、强大的调用已编译函数的方式是 .Call()，它能处理更多类型的 R 对象，但显著增加编程复杂度。.Call() 是 R 较新的添加，因此语言的大部分是用简单但不灵活的 .C() 写成的。

9.10 从 C 调用 R 函数

从 R 调用的已编译 C 代码也可以调用某些 R 函数（Fortran 不行）。特别是与抽取及计算统计分布相关的函数可用。要访问这些函数，必须包含头文件 Rmath.h。可惜这些 C 函数文档不多，程序员可能需要在本机系统的 Rmath.h 中查找其定义。调用这些函数前必须调用 GetRNGstate()，之后必须调用 PutRNGstate()。下面是一个生成带 N(0,1) 误差与给定系数的 AR(1) 序列的 C 函数：

#include<Rmath.h>
void ar1(double *y,double *rho,double *N){
  int i;
  GetRNGstate();
  for (i=1;i<N[0];i++){
    y[i]=rho[0]*y[i-1]+rnorm(0.0,1.0);
  }
  PutRNGstate();
}

可按惯例从 R 内调用：

> dyn.load("ar1.so")
> X<-.C("ar1",x=double(len=5000),rho=as.double(.9),
+        n=as.integer(5000))$x

大多数常见数学运算（如 sqrt()）也可通过 C 接口使用。也可从 C 内调用实际的 R 表达式，但不推荐：这会启动新的 R 实例，比结束 C 代码、在 R 中计算、再调用另一个 C 函数更慢。做法是使用（现已弃用的）call_R() 函数。
